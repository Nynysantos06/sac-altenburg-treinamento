# Central de Formação · SAC Altenburg

Projeto preparado para publicação no GitHub + Cloudflare Pages.

## Publicação
1. Conecte este repositório ao Cloudflare Pages.
2. Use a raiz do repositório como diretório do projeto.
3. Não é necessário comando de build para a versão estática.

## Dados
A plataforma possui salvamento local e backup/importação. Para compartilhar os mesmos dados entre vários usuários, é necessário usar o Firebase/Firestore configurado na plataforma.
